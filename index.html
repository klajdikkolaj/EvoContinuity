What Eternia is

A private world journal where meaning becomes place.

Eternia starts with a simple product promise: write a meaningful idea, review the symbolic place it becomes, save it privately, and return when you want to extend it.

The deeper ambition is a lawful mythic world, but the public wedge stays clear: private by default, saved places, visible boundaries.

03

Review before saving

Interpretation and retrieval can help shape a place, but saved world state stays behind explicit boundaries.

FAQ

Clear answers for first-time visitors.

Is Eternia a game?

No. It uses world-based interaction and visual spaces, but the first public product wedge is a private world journal where meaningful ideas become revisitable places.

Is Eternia just an AI companion app?

No. Companions are part of it, but Eternia is a governed world, not just a chat interface.

Do AI beings control the world?

No. Important changes happen through explicit rules, review, and reversible steps.

Is this mind uploading?

No. Today, Eternia is framed as a private, consent-first worldbuilding journal with strong boundaries around memory, signals, model evidence, and world change.

What makes Eternia different?

It combines symbolic place-making, privacy boundaries, governed saving, and long-term co-evolution direction without turning private source text into public product content.

What is the public repo?

The public repo is a clean showcase and static demo for Eternia. It does not contain the private runtime, provider pipelines, memory systems, model-lab execution code, or world-mutation authority.
